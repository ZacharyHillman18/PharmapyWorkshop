# PharmaPy workshop

Hands-on notebooks for [PharmaPy](https://github.com/PharmaPy-org/PharmaPy), a Python framework for simulating pharmaceutical processes: reactors, crystallizers, filters and the flowsheets that connect them. You build models, run them, and optimize them with `scipy.optimize`.

Click an **Open in Colab** badge to run a notebook in Google Colab, with nothing to install. Work through one track, in order.

## Using Colab

1. Click a badge. The notebook opens in Colab.
2. Run the first code cell, **Colab setup**. It installs PharmaPy and unpacks the notebook's data files (about half a minute).
3. Run the cells from top to bottom, filling in the lines marked `# <-- COMPLETE THIS`.
4. Use *File → Save a copy in Drive* to keep your work. Changes to a notebook opened from a badge are not saved otherwise.

Each notebook runs on its own Colab machine, so run the setup cell in every notebook you open. After a runtime restart or disconnect, run the setup cell again, then the cells above the one you were working on.

## Running on your own computer

You need Python 3.9 or newer:

```bash
pip install "pharmapy-org>=0.3.1" jupyter
git clone https://github.com/ZacharyHillman18/PharmapyWorkshop.git
cd PharmapyWorkshop
jupyter lab
```

Each folder also holds `data/` and `workshop_utils.py`, and the setup cell skips the install when PharmaPy is already there.
